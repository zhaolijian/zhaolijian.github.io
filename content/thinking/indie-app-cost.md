经常有人问我「一个人做一个 App 大概要花多少钱」。我一般先反问：你说的「做出来」是指能演示，还是能上架，还是能持续运营？

这三个阶段的成本差着一个量级。而且真正贵的不是钱，是时间和卡点。

## 工具与技术栈：一年几百到几千元量级

先说我选技术栈的标准，不是「先进」，是总拥有成本：AI 辅助生态成熟、社区资料多、踩坑成本低。按这个标准，跨端用 Expo + React Native + TypeScript，后端用 Hono 或 Serverless，数据库和对象存储按量付费，再配域名、证书、图标字体、崩溃监控。

选型时看三个具体指标：这个技术栈最近的版本更新活跃不活跃、遇到问题能不能搜到答案、AI 写这个框架的代码准不准。最后一条现在越来越重要——同样的需求，AI 对某个框架的代码生成质量，直接决定一个人一天能做多少事。

钱的部分其实不吓人。个人开发，工具、服务器、域名、监控加起来大致是「一年几百到几千元」这个量级；AI 模型的调用费用看用量，用得多就没有上限。真正持续的成本在上线之后：服务器、模型调用、客服、合规维护、版本更新。

我踩过的一个坑是「为可能用到的东西提前付费」：一次买长期套餐、一次接三个 SDK，最后大部分没用上。独立开发的原则应该是先用免费档跑通主流程，等确实卡住了再花钱。

## 上架合规：最容易被低估的一块

这部分比技术更麻烦，因为它不是能力问题，是流程问题。

国内上架，大致要走：法律主体与开发者账号、APP 备案（工信部）、ICP 域名备案、公安备案、软著（多数安卓商店要求）、AI 备案（涉及生成式 AI）、AI 生成内容标识、隐私政策与个人信息处理规则，然后各安卓商店逐家注册、逐家提审。

海外上架是另一套：开发者账号、隐私标签、ATT 与广告归因、GDPR / CCPA / COPPA、CMP 同意管理、数据查询与删除接口。

合规里最容易踩的坑不是「不知道要备案」，是「备案和产品没对齐」：接一个第三方 SDK 就要回看隐私披露，加一个 AI 功能就可能触发 AI 备案和生成内容标识，改一次支付方式就要重看商店规则。它不是一个阶段，是贯穿整个开发过程的一条线。

周期只能给量级：备案类以月计（通常一到两个月），软著普通周期一个月左右、加急一周多，开发者账号以周计，审核被拒重来还要另算。它们是前置串行的，经常是整个项目里最没有弹性的一段——你没法用加班把审批压短。

想省这块成本，最有效的动作是「一开始就决定主攻哪个市场」。双区运营等于两套合规、两套支付、两套商店、两套税务，多数个人开发者的正确选择是先做单市场。

## 时间账：从立项到能给人用

我自己的几个项目可以拆开看。阅记从调研、四十多款竞品对比、PRD、原型，到前后端实现和真机内测；颜配从技术验证到产品形态验证；GEO 是 B 端，从诊断、内容到分发、回测整条链路。

单看「写代码」的时间不算长。但从立项到能交给真实用户使用，通常是三到六个月量级。按我的经验，时间大致分布成三块：调研与需求收敛、开发、测试合规上架，比例接近 3:4:3（个人经验，不是统计）。

最容易低估的三件事：备案排队、审核拒稿重来、上架后的运营（客服、更新、数据）。任何一件都可能把计划打乱一个月。还有大量时间是「等」：等审核、等备案、等软著。等的时间不能压缩，能做的只是把它和开发并行——所以启动合规的时间点要提前到写第一行代码之前，而不是产品做完了才想起来。

上线之后的成本是另一笔账：服务器和模型调用随用户量涨，客服和反馈要有人回，版本更新要跟系统升级，合规材料要定期维护。这些成本不会一次出现，但每个月都在。

还有一项隐形成本——注意力。一个人同时做产品、开发、合规、客服，切换一次上下文就是半小时，一天下来真正有效的整块时间没有多少。所以时间账不能只按工作日算，要按「能连续投入的整块时间」算。

## 不成立的条件

- **品类差异极大。** 工具类和内容、社交类不是一回事，后者有 UGC 审核和内容安全成本；医疗、健康、金融类前置资质更重；自研模型和调 API 的合规周期差一个量级。
- **国内和海外不是同一道题。** 主体、备案、支付、商店、税务全都要各算一遍，不能拿一个市场的经验估另一个市场。
- **「几百块做一个 App」在演示层成立，在「能上架、能持续运营」层不成立。**
- **反过来也不必等资质齐了才开工。** 先用不需要上架的原型验证价值，再为合规付费；顺序反了，很容易在验证之前就把钱和时间花光。
- **「一个人」和「一个人 + 外包」是两个成本结构。** 设计、视频、法务、财务可以外包，但每外包一项就多一次沟通和验收成本；预算不够时，先砍掉非核心的自研，把外包花在能直接过审或直接带来用户的地方。
- **我的数字只有量级意义。** 不同品类、不同市场、不同主体，差异比我给出的区间大得多，别拿它当预算表。

所以我现在给别人的建议，会把「花多少钱」换成「花多少时间、卡在哪一步」。后者才是决定一个人能不能把这个 App 做完的东西。
